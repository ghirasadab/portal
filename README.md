# بوابة المعلمين — غراس الأدب

الصفحة التي يفتحها المعلم على `portal.ghiras-adab.com` ليسجّل الحصة ويكتب تقريرها.

- لكل معلم رابط خاص فيه رمز سري: `https://portal.ghiras-adab.com/?t=...`
- البيانات لا تُحفظ هنا؛ الصفحة تتصل بتطبيق ويب في Google Apps Script يكتب في شيت المعلم ويحفظ التقارير.
- العرض التجريبي ببيانات وهمية: `https://portal.ghiras-adab.com/?demo=1`

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم بهوية موقع غراس الأدب |
| `app.js` | منطق الصفحة والاتصال بالخادم |
| `config.js` | عنوان تطبيق الويب (Apps Script) |
| `demo.js` | بيانات العرض التجريبي |
| `CNAME` | ربط النطاق الفرعي |
